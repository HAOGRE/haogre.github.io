# 《我的世界100天天空冒险》设计说明

## 目标

将桌面上的 `mc-story-3.md` 从按天罗列的故事大纲扩写为一篇可独立阅读的中文故事博客，保留史蒂夫、艾利克斯、胖胖和冰霜巨龙的角色关系、轻松笑点与“信任让冒险完成”的主题，并发布到现有 Astro 博客。

## 内容方案

- 采用“百日冒险回忆录”的连续叙事，而不是逐日流水账。
- 用六个阶段组织故事：出发与基地、火山与冰霜线索、天空浮岛、天空试炼、暗影战争、百日完成。
- 保留大纲中的关键事件：护身符、海洋霸主、天空羽毛、金羽鹰王、天空圣甲、冰霜巨龙孵化、暗影终焉之王和回家。
- 胖胖承担喜剧节奏，艾利克斯承担路线与策略，史蒂夫承担行动主线；最终冲突解决依靠协作而非单一英雄。
- 正文使用现有中文文章的短段落、对白和图注风格，避免把“第 1 天到第 100 天”逐条扩成重复日志。

## 配图方案

生成 7 张 16:9 横版叙事插图，使用桌面上既有 Minecraft 故事配图的白底黑线稿、少量蓝紫橙高亮和手写批注作为视觉参考，但不复用原图：

1. 三人建立天空基地并第一次看到护身符。
2. 火山口中出现冰蓝色龙眼。
3. 海洋霸主与三人的水下战斗。
4. 三人踏上天空浮岛的云桥。
5. 冰霜龙蛋孵化，幼龙认出史蒂夫。
6. 暗影风暴领主撕裂天空，四人准备最终战。
7. 百日完成后，三人骑着成长后的冰霜巨龙飞回家。

图片存放在 `public/uploads/2026/08/20/我的世界100天天空冒险/`，正文以绝对站点路径引用并附中文图注。

## 站点接入

- 中文文章写入 `src/content/posts/2026/08/20/我的世界100天天空冒险.md`。
- 使用现有 `npm run publish -- --stage` 流程生成英文伴侣；若生成结果不可用，则保留中文文章并用站点已有翻译格式手工补齐。
- frontmatter 使用 `author: HAOGRE`、当前日期、`featured: false`、`draft: false`、`translationKey`、3–5 个中文标签和一句摘要。
- 不修改仓库中本次任务之外的未跟踪实验文件。

## 验收

- Markdown frontmatter 可被 Astro content schema 解析。
- 中文与英文文章的图片路径全部存在。
- `npm test`、`npm run lint`、`npm run format:check` 和 `npm run build` 成功。
- 预览或生成产物中能找到中文文章的标题、正文、图像和 RSS 页面。
- 提交并推送到远端后，检查 GitHub Actions / Pages 状态和站点 URL。
