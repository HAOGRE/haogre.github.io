# 可导流 404 页面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 改造中英文 404 页面，在保留真实 404 状态的同时提供搜索、最近文章和文章列表入口。

**Architecture:** 在现有 `src/pages/404.astro` 中构建时读取当前语言的 posts collection，复用 `getSortedPosts` 和 `Card` 展示最近 3 篇文章；通过现有 i18n 文案提供中英文提示和按钮文本。未知 URL 不增加重定向逻辑。

**Tech Stack:** Astro、Astro Content Collections、TypeScript、现有 Tailwind/组件体系。

## Global Constraints

- 保留真实 404 路由语义，不将未知 URL 统一重定向到首页。
- 只展示通过现有 `postFilter` 的非草稿、非未来文章。
- 最近文章按现有 `getSortedPosts` 规则排序，中文/英文页面只展示对应语言文章。
- 不修改文章 URL、canonical、sitemap 或 GA4 配置。
- 不包含仓库现有未跟踪文件：`generate_all_images.sh`、`new_images/`、`replace_images.sh`、`src/content/posts/test.jpg`、`test.jpg`。

### Task 2: Build the recoverable 404 page

**Files:**
- Modify: `/Users/haogre/github/haogre.github.io/src/pages/404.astro`

**Interfaces:**
- Consumes: `getCollection("posts")`, `getSortedPosts`, `Card`, `getRelativeLocaleUrl`, and `t.notFound`.
- Produces: localized static 404 pages with search, recent-post, home, and all-post links.

- [ ] **Step 1: Load the current-language posts**

Add these imports:

```ts
import { getCollection } from "astro:content";
import Card from "@/components/Card.astro";
import { getSortedPosts } from "@/utils/getSortedPosts";
```

After the existing locale and translation setup, add:

```ts
const isEnLocale = locale === "en";
const posts = await getCollection(
  "posts",
  ({ data }) => isEnLocale ? data.lang === "en" : data.lang !== "en"
);
const recentPosts = getSortedPosts(posts).slice(0, 3);
```

- [ ] **Step 2: Add the search and all-post links**

Define these paths beside the locale setup:

```ts
const homePath = getRelativeLocaleUrl(locale, "");
const searchPath = getRelativeLocaleUrl(locale, "search");
const postsPath = getRelativeLocaleUrl(locale, "posts");
```

Render the existing message followed by a link group containing:

```astro
<div class="my-6 flex flex-wrap justify-center gap-x-6 gap-y-2 text-lg">
  <LinkButton href={searchPath} class="underline decoration-dashed underline-offset-8">
    {t.notFound.searchPosts}
  </LinkButton>
  <LinkButton href={postsPath} class="underline decoration-dashed underline-offset-8">
    {t.notFound.allPosts}
  </LinkButton>
</div>
```

Keep the existing home link, but use `homePath` instead of recomputing the path inline.

- [ ] **Step 3: Render the recent articles**

Below the 404 action links, render the section only when `recentPosts.length > 0`:

```astro
{recentPosts.length > 0 && (
  <section class="mt-10 w-full max-w-2xl text-left">
    <h2 class="border-border border-b pb-3 text-2xl font-semibold tracking-wide">
      {t.notFound.recentPosts}
    </h2>
    <ul>
      {recentPosts.map(post => <Card variant="h3" {...post} />)}
    </ul>
  </section>
)}
```

Use the existing page layout classes so the new section remains readable on mobile and desktop.
